02 · Projects & Journey

Small projects. Real learning.

These projects and activities are part of my learning journey so far. Each one has helped me build a different part of my foundation—from version control and collaboration to problem solving, application development, and IoT.

01 / GIT & GITHUB

Hello World GitHub Repository

This was one of my first steps into Git and GitHub. I created and worked with a simple Hello World repository, added files, made commits, tracked changes, and maintained the code online.

What I learned: I became familiar with the basic GitHub workflow and understood how source code can be stored, managed, version-controlled, and shared as part of a public coding portfolio.
02 / COLLABORATION

Pair Programming & Collaboration

I participated in a pair-programming activity using Git, GitHub, GitLens, and Live Share. I explored how developers can collaborate on programming tasks, share development environments, and keep track of changes through commits.

What I learned: I learned that software development is not always an individual activity. Communication, collaboration, Git workflows, change tracking, and teamwork are important parts of development.
03 / PROBLEM SOLVING

LeetCode Problem-Solving Repository

I practiced programming problems and maintained my solutions using GitHub. The work focused on understanding problems, breaking them into smaller steps, designing logical solutions, writing and testing code, debugging errors, and documenting my practice.

What I learned: This strengthened my programming logic, problem-solving approach, debugging habits, programming fundamentals, and ability to document technical work. I want to continue expanding this repository as I practice more Data Structures & Algorithms problems.
04 / PYTHON & STREAMLIT

Python SIP Calculator

I explored Python application development through a SIP Calculator, combining programming logic with a simple user interface. I also explored Streamlit for creating interactive Python-based applications.

What I learned: I learned how programming logic can be connected to a simple user-facing application and gained practical exposure to Streamlit application development.
05 / ARDUINO & IOT

Arduino-based Smart Parking System

I explored IoT through an Arduino-based Smart Parking System using an Arduino UNO, ultrasonic sensor, LCD with I2C, LEDs, resistors, breadboard, and servo motor. The project helped me connect programming with sensors and embedded components.

What I learned: I gained a practical understanding of how software can interact with sensors, electronic components, and real-world systems, strengthening my interest in IoT and hands-on technology projects.
